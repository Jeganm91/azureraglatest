# System Access Request Process (v2.0 — Effective March 1, 2026)

This document describes the current, authoritative process for requesting access to
internal systems.

## Step 1: Submit a Request
Employees submit an access request through the Internal Access Portal
(https://access.internal.example.com). The request must include:
- Employee ID
- System(s) requested
- Business justification
- Requested access duration (temporary or permanent)

## Step 2: Manager Approval
The employee's direct manager must approve the request within the portal. Requests
without manager approval are automatically closed after 5 business days.

## Step 3: Security Review (for privileged/elevated access only)
If the requested access is classified as **privileged** (e.g., admin rights,
production database access, root/sudo access), the request is routed to the
**Security Officer** for a mandatory security review. Standard (non-privileged)
access does not require this step.

## Step 4: Provisioning
Once approved, the IT Operations team provisions access within 1 business day.
The employee receives an email confirmation with access details and an expiration
date, if applicable.

## Required Supporting Information
- Manager's name and email
- Business justification (minimum 1 sentence)
- Data classification of systems being accessed (if applicable)
- For privileged access: a completed Privileged Access Justification Form
