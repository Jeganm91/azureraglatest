# System Access Request Process (v1.0 — Effective June 15, 2023)

Employees who need access to internal systems should email the IT Helpdesk at
it-helpdesk@example.com with their manager's name and the system name.

Approval for any elevated or administrative access is granted by the **Team Lead**
of the requesting employee's department. There is no separate security review step.

Once approved by the Team Lead, IT Helpdesk provisions access within 3-5 business
days.

## Required Information
- Employee name
- Manager name
- System requested

Note: This process has since been replaced by a portal-based workflow. This document
is retained for historical reference only.
