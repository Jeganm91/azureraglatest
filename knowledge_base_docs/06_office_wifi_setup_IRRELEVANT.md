# Office WiFi Setup Guide

To connect to the office WiFi network:

1. Select "CorpNet-Secure" from your device's WiFi list.
2. Enter your corporate username and password (same as your email login).
3. Accept the certificate prompt if shown.
4. Guests should use "CorpNet-Guest" and request a temporary code from the
   front desk.

For connectivity issues, contact IT Support at it-support@example.com.
