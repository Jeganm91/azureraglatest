# How to Request System Access — Employee FAQ

New employees often ask how to get access to internal systems. Here's a quick
summary:

1. Go to the Internal Access Portal and submit a request.
2. Your manager needs to approve it.
3. If it's for something sensitive (admin/privileged access), there's an extra
   security review step.
4. Once approved, IT sets it up, usually within a day.

Make sure you include why you need the access (business justification) when you
submit the request, plus which system(s) you need.

For questions, contact your onboarding buddy or IT support.
