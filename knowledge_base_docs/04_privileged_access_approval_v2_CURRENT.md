# Privileged System Access Approval Policy (v2.1 — Effective January 10, 2026)

Privileged system access (administrator rights, production database access,
root/sudo access, or access to systems classified as Tier 1 Critical) requires
approval from the **Security Officer**, in addition to standard manager approval.

## Approval Chain for Privileged Access
1. Employee submits the request via the Internal Access Portal.
2. Manager approves the business justification.
3. **Security Officer** reviews and approves the security risk, scope, and
   duration of privileged access.
4. Access is time-boxed by default (max 90 days) unless explicitly justified
   otherwise and re-approved by the Security Officer.

## Required Supporting Documentation
- Privileged Access Justification Form
- Data classification of systems being accessed
- Planned access duration

This policy is the sole authoritative source for privileged access approval
as of the effective date above. It supersedes any prior policy referencing
Team Lead approval for privileged access.
